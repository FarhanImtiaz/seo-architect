# New page

Inspect routes and existing content first. Decide whether a new URL, an existing page update, or a section best satisfies the intent. For an approved page define intent, query themes, URL, title/H1/meta, outline, inbound/outbound links, appropriate schema, direct-answer block, CTA, and evidence needed; validate the relevant page-type contract before implementation. Implement only what project facts support and validate. Do not create a duplicate-intent URL or doorway page.
