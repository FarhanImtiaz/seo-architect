# Report

Produce a compact management report from state and current checks: health, priority issues, completed changes, pages created/optimized, content/AEO/authority opportunities, and next ten evidence-based actions. State unavailable data rather than fabricating metrics.

Frame measurement expectations using [references/winning-patterns.md](../references/winning-patterns.md) P01 (a change's effect is unknown until measured, on this site, not assumed from another site's result), P07 (refresh candidates need authorized data to move past hypothesis), and P13 (Ahrefs' own observational data shows AI Overviews correlate with lower top-result CTR — a useful honest baseline, not a target).

If the user has Search Console/GA4/PageSpeed/CrUX access, offer `scripts/live_data.py` (see [references/measurement.md](../references/measurement.md)) — but only after asking; never run it unprompted or treat its absence as blocking the report.
