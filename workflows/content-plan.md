# Content plan

Create a connected topic plan in `.claude/seo/content-plan.md`. Each item needs audience, intent, cluster, URL, themes, title, outline, links, CTA, evidence, schema, and freshness. Prioritize work that supports a commercial journey and real expertise; reject quota-driven filler.

Apply [references/winning-patterns.md](../references/winning-patterns.md) P05 (pillar/cluster grouping), P06 (business-potential score per item, reject 0s), P06b (off-topic-volume caution), and P07 (prioritize refreshing existing traffic-earning pages, when authorized measurement data identifies them) before finalizing priority order.
