# Keywords

Build clusters in `.claude/seo/keywords.md`, not a disconnected list. Map each cluster to one target URL and record topic, queries, intent, funnel, priority, status, gap, and internal-link targets. Use current web research only when available and clearly label observations; never invent volume.

Score each cluster's business potential 0-3 per [references/winning-patterns.md](../references/winning-patterns.md) P06 (3 = the product is an indispensable solution to the topic, 0 = no natural way to mention it) in the Business-potential column of `templates/keywords.md`; reject 0s.
