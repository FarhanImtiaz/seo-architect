# Setup and status

Inspect repository files first: framework/router, SSR/SSG/static behavior, package manager/build, metadata, sitemap/robots, canonical/OG/schema, analytics hints, CMS/content, navigation/footer, redirects, locale, and route inventory. Run `full_audit.py . --initialize --snapshot` to establish the static SEO+AEO baseline without overwriting facts. Produce current state, architecture map, technical risks, opportunities, AEO readiness, and a prioritized backlog. `status` reads state and reruns only checks affected by recent changes. Never rewrite a site merely because setup ran.
