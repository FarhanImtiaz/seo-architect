# Measurement

Use codebase evidence by default. When authorized data is available, report its source/date and observed indexed URLs, queries, impressions, clicks, CTR, position, landing pages, conversions, referring domains, and AI mentions. Missing data remains missing—do not estimate it as fact.

`scripts/live_data.py` is a strictly opt-in adapter for when a user has authorized data access — never run it without asking first, and never treat its absence as a blocker for static work. `import-gsc`/`import-ga4` parse a manual CSV export (no credentials); `psi` calls PageSpeed Insights (works without a key, `PSI_API_KEY` optional from the environment); `crux` requires `CRUX_API_KEY` from the environment and fails closed with no key, never fabricating field data. Every import writes a dated, source-labeled snapshot to `.claude/seo/measurement/` and refuses to import a CSV row containing a secret-like value. When CrUX field data is present, `score.py`'s Performance category uses it in place of the static image proxies (see [references/scoring-rubric.md](scoring-rubric.md)). Gate any of this behind `config.json`'s `tracking` flags, and never write an API key to disk.
