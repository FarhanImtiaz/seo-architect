# SEO principles

Prioritize: indexability, coherent architecture, intent satisfaction, useful original material, contextual internal links, accurate markup, and accessible fast delivery. AEO is the same quality work expressed as explicit answers, clear entities, and evidence that a system can extract and trust.

Never claim a ranking, citation, rich result, or indexation outcome is guaranteed. Use keyword themes, not density targets. A page exists because it uniquely serves an intent, not because a phrase has a variant.
