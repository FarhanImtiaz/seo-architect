# Structured data

Use Organization, WebSite, WebPage, BreadcrumbList, Service, Article/BlogPosting, Product, LocalBusiness, or FAQPage only when the visible page supports every material assertion. Parse JSON-LD locally, then use a relevant rich-results/schema validator when available. Never add ratings, reviews, pricing, availability, eligibility, authorship, or locations without visible evidence.

`scripts/seo_tools.py jsonld` validates required/recommended properties per `@type` against `scripts/schema_rules.json` (Product, Article/BlogPosting/NewsArticle, BreadcrumbList, Organization, WebSite, LocalBusiness, Event, JobPosting, Review, AggregateRating, FAQPage, HowTo, VideoObject, Recipe, Service), walking `@graph` and nested objects (Offer inside Product, etc.). A missing Google-required property is HIGH; a missing recommended property is LOW; an unrecognized `@type` is INFO for manual review. It also flags `aggregateRating.ratingValue`, `offers.price`, and `LocalBusiness.address` as MEDIUM when the value isn't present in the same file's visible text — this enforces "never assert unsupported schema" in code, not just in prose. FAQPage is flagged `volatile` (Google restricted FAQ rich results in Aug 2023) and HowTo is `deprecated` (INFO only, not a ranking lever) — re-verify these against current Google documentation before relying on them.
